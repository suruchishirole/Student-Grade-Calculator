# 🎓 Student Grade Calculator
A simple Python project that calculates a student's grade based on marks entered (0–100) and displays an encouraging message.

## ✨ Features
- Grade calculation using `if-elif-else`
- Input validation for student name and marks
- `while` loops to handle invalid inputs
- Functions and exception handling
- Encouraging messages for each grade

## 📊 Grading Criteria
- **A:** 90–100
- **B:** 80–89.99
- **C:** 70–79.99
- **D:** 60–69.99
- **F:** Below 60

## 🛠️ Technologies
- Python 3.x

## 📁 Project Structure
- `student_grade_calculator.py` – Main Python program
- `README.md` – Project documentation
- `screenshot.png` – Program output screenshot

## 🎯 Objective
To practice Python fundamentals, including functions, conditional statements, loops, and input validation, through a simple and useful application.
